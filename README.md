# quietmuseum.com

Website for Quiet Museum: Jigsaw Puzzles. Plain HTML and CSS served by GitHub Pages at https://quietmuseum.com.

- `index.html` home
- `privacy/index.html` privacy policy (linked from Google Play)
- `support/index.html` support and FAQ
- `CNAME` custom domain for GitHub Pages

Before the app launches: add the Google Play link to the home page, switch the contact address to support@quietmuseum.com once forwarding works, and re-check the privacy policy against the final app.
